Interface record · October 29, 2026

Variance Metrics is a board-measurement analysis workspace used in my AnTrust project. The interface is organized into an overview, feature analysis, a board map, a data explorer, and report settings.

Controls and views

  • Board and feature selectors determine the records displayed.
  • Summary panels show reading counts and exclusions.
  • Distribution plots and a heatmap provide different views of the selected data.
  • Source references accompany the measurement records.
  • Report settings control which plots and tables are included in an export.
