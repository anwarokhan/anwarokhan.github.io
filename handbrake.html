DIY handbrake

Read the original project log ↗

A very specific need

In DiRT Rally 2.0, I wanted a physical handbrake rather than a button on the wheel. I designed a printed enclosure and used a potentiometer to read the lever position. CircuitPython let the Circuit Playground Express identify as a game controller.

Working is one milestone

Getting the game to recognize the input was a milestone. Making the assembly feel solid was another problem. The project page describes a frame that was still wobbly and considers a stronger print or machined parts.

The potentiometer measures position. Some older prose on the site calls it a force sensor or a load cell; that description does not match the documented control.

Keeping the timeline honest

The blog post is dated October 2023, while several build-log entries say October 2024 and the project page was published in February 2025. These are existing source dates, not evidence of a single confirmed completion day.
